# 정렬 필터 — 카테고리 상세 화면

## 결정 요약

- **적용 범위**: 카테고리 상세 화면만
- **옵션**: 시간(최신순) / 금액(큰순) 2개 고정, 방향 토글 없음
- **상태 저장**: `state.sortBy` (`'date'` | `'amount'`), 영구 저장
- **UI**: 기록 라벨 행 우측에 작은 칩 두 개. 활성 칩은 `--ink` 채움.

## 변경 파일

- `script.js` — `defaultState()`에 `sortBy: 'date'` 추가, `renderCategory()`에서 정렬·칩 렌더 + 클릭 핸들러
- `style.css` — `.sort-chips`, `.sort-chip`, `.sort-chip.is-active` 추가

## 구현

### script.js — defaultState

```js
function defaultState() {
  return { currentMonth: monthKey(new Date()), expenses: [], budgets: {}, templates: [], sortBy: 'date' };
}
```

`Object.assign(defaultState(), s)` 패턴이라 기존 사용자 데이터엔 `sortBy: 'date'`가 자동으로 주입됨. 별도 마이그레이션 불필요.

### script.js — renderCategory 내부

```js
const sortBy = state.sortBy || 'date';
const ex = getMonthExpenses(month).filter(e => e.category === cat).sort((a,b) =>
  sortBy === 'amount' ? b.amount - a.amount : b.date.localeCompare(a.date)
);
```

기록 라벨 행 부분 교체:

```js
const hasMultiple = ex.length > 1;
if (showTemplates || hasMultiple) {
  const labelHtml = showTemplates ? '<span>기록</span>' : '<span></span>';
  const chipsHtml = hasMultiple ? `
    <div class="sort-chips">
      <button class="sort-chip ${sortBy === 'date' ? 'is-active' : ''}" data-sort="date">시간</button>
      <button class="sort-chip ${sortBy === 'amount' ? 'is-active' : ''}" data-sort="amount">금액</button>
    </div>` : '';
  const row = el(`<div class="section-label entries-label">${labelHtml}${chipsHtml}</div>`);
  if (hasMultiple) {
    row.querySelectorAll('.sort-chip').forEach(btn => {
      btn.addEventListener('click', () => {
        const v = btn.dataset.sort;
        if (state.sortBy === v) return;
        state.sortBy = v;
        saveState();
        render();
      });
    });
  }
  app.appendChild(row);
}
```

### style.css

`.cat-chip` 블록 다음에 추가:

```css
.sort-chips {
  display: flex;
  gap: 4px;
}
.sort-chip {
  background: transparent;
  border: 1px solid var(--rule);
  border-radius: 999px;
  padding: 4px 10px;
  font-family: var(--font-body);
  font-size: 11px;
  font-weight: 500;
  color: var(--ink-soft);
  letter-spacing: 0.02em;
  cursor: pointer;
  transition: all 180ms var(--ease-snap);
  text-transform: none;
}
.sort-chip.is-active {
  background: var(--ink);
  color: var(--paper);
  border-color: var(--ink);
}
.sort-chip:active { transform: scale(0.94); }
```

`.section-label`이 `text-transform: uppercase`인데 칩에는 영향 안 가도록 `text-transform: none`을 명시.

## 검증

- 카테고리 상세 진입 → 기록 행 우측에 "시간/금액" 칩, "시간"이 활성
- "금액" 탭 → 큰 금액부터 정렬, 칩 활성 상태 토글
- 다른 카테고리/월/홈으로 이동 후 다시 진입 → 마지막 선택 유지
- 항목 1개일 때 칩 미노출

## 비목표

- 오래된순/작은순 방향 반전
- 홈 화면 카테고리 카드 정렬

- 메모/카테고리 등 추가 정렬 기준
