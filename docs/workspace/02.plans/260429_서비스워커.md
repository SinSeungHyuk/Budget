# Service Worker — 오프라인 + 캐시 구현 플랜

## 목표

- 오프라인에서도 앱 동작
- 캐시된 자원으로 두 번째 진입부터 즉시 로드
- 코드 업데이트는 다음 실행 시 자연스럽게 반영 (별도 토스트 없음)

## 파일

- **신규**: `sw.js`
- **수정**: `index.html` — SW 등록 스크립트 추가

## 캐시 전략

| 자원 | 전략 | 이유 |
|---|---|---|
| 앱 셸 (`./`, `index.html`, `script.js`, `style.css`, `manifest.json`, `icon.svg`) | **cache-first** | 오프라인 동작 + 즉시 로드. 업데이트는 SW 재활성화 시 |
| Google Fonts (CSS + woff2) | **stale-while-revalidate** | 처음에는 캐시된 거 바로 보여주고 백그라운드로 최신 받기 |
| 그 외 (외부 GET) | **stale-while-revalidate** | 안전한 기본값 |
| POST/PUT/DELETE | 패스 | 캐시 안 함 |

## SW 라이프사이클

- `install`: APP_SHELL precache → `skipWaiting()`
- `activate`: 다른 버전 캐시 삭제 → `clients.claim()`
- 결과: 사용자가 앱 닫았다가 다시 열면 새 버전 로드. 별다른 안내 UI 없음.

## 구현 단계

### 1. `sw.js` 작성

```js
const CACHE = 'budget-v1';
const APP_SHELL = [
  './',
  './index.html',
  './script.js',
  './style.css',
  './manifest.json',
  './icon.svg',
];

self.addEventListener('install', (e) => {
  e.waitUntil(
    caches.open(CACHE)
      .then((c) => c.addAll(APP_SHELL))
      .then(() => self.skipWaiting())
  );
});

self.addEventListener('activate', (e) => {
  e.waitUntil(
    caches.keys()
      .then((keys) => Promise.all(
        keys.filter((k) => k !== CACHE).map((k) => caches.delete(k))
      ))
      .then(() => self.clients.claim())
  );
});

self.addEventListener('fetch', (e) => {
  const req = e.request;
  if (req.method !== 'GET') return;

  const url = new URL(req.url);
  const sameOrigin = url.origin === location.origin;

  if (sameOrigin) {
    // cache-first
    e.respondWith(
      caches.match(req).then((hit) => hit || fetch(req).then((res) => {
        if (res.ok) {
          const copy = res.clone();
          caches.open(CACHE).then((c) => c.put(req, copy));
        }
        return res;
      }).catch(() => caches.match('./index.html')))
    );
  } else {
    // stale-while-revalidate
    e.respondWith(
      caches.match(req).then((hit) => {
        const networked = fetch(req).then((res) => {
          if (res.ok) {
            const copy = res.clone();
            caches.open(CACHE).then((c) => c.put(req, copy));
          }
          return res;
        }).catch(() => hit);
        return hit || networked;
      })
    );
  }
});
```

### 2. `index.html` SW 등록

`</body>` 직전 `<script src="script.js"></script>` 다음에:

```html
<script>
  if ('serviceWorker' in navigator) {
    window.addEventListener('load', () => {
      navigator.serviceWorker.register('./sw.js').catch(() => {});
    });
  }
</script>
```

### 3. 검증

- `python -m http.server 8000` 후 DevTools → Application → Service Workers에서 등록 확인
- Network 탭 "Offline" 체크 → 새로고침해도 앱 정상 표시
- Cache Storage에 `budget-v1`이 생성되고 6개 항목 들어있는지 확인

### 4. 커밋 + 푸시

```
feat: add service worker for offline support
```

## 캐시 버전 운영

코드를 크게 바꿔 강제 캐시 무효화가 필요할 때만 `CACHE = 'budget-v1'` → `'budget-v2'`로 올림. 일상적인 수정은 같은 버전 유지 — SW는 새 파일이 들어오면 알아서 fetch해서 cache.put 함.

## 비목표

- 업데이트 알림 토스트 (사용자가 "별다른 처리 안 해도 된다"고 명시)
- 푸시 알림
- 백그라운드 동기화
- IndexedDB 마이그레이션
