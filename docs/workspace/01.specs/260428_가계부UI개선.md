# 가계부 UI 개선 — 1차 피드백 반영

## 배경

`index.html`/`script.js`/`style.css` 3-파일 정적 PWA. 모바일 가계부. 첫 사용 후 사용자 피드백 6건 반영.

## 변경 항목

### 1. 숫자 폰트 교체 + 사이즈 다운

**현재**: 모든 금액에 `Fraunces` (variable serif). Total 36px, 카드 30px, 상세 28px, 항목 21px, 입력 40px.

**변경 후**: `IBM Plex Mono` (Google Fonts). 사이즈 25~30% 다운.

| 항목 | 현재 | 변경 |
|---|---|---|
| `.summary-amount` | 36px | 26px |
| `.summary-amount .currency` | 19px | 14px |
| `.card-amount` | 30px | 22px |
| `.card-amount .limit` | 13px | 12px |
| `.detail-title-amount` | 28px | 20px |
| `.detail-title-amount .currency` | 18px | 13px |
| `.entry-amount` | 21px | 16px |
| `.field-input.is-amount` | 40px | 28px |

`Fraunces`는 다음 위치에 한정해서 유지:
- `.modal-title` (모달 타이틀)
- `.empty-state-mark` (∅ 심볼)
- `.brand` (풋터 워터마크)
- `.card-pct.dash` (— 표시)

`--font-mono: 'IBM Plex Mono', ui-monospace, 'SF Mono', Menlo, monospace` 토큰을 `:root`에 추가.

### 2. 헤더 월 클릭 → 바텀시트 연도/월 피커

**트리거**: `.month-display` 영역(연도+월 텍스트) 탭.

**구성**:
- 상단: `‹ 2026 ›` 연도 스텝퍼 (좌우 화살표)
- 그 아래: 4×3 그리드 (Jan~Dec). 화면 폭 좁으니 3×4 또는 4×3 중 균형 좋은 쪽.
- 시각 상태:
  - 현재 보고 있는 달: `--ink` 채움, 흰 글씨
  - 오늘 달(real current month): 우측 상단에 작은 점 표시 (0.5em 원, `--olive`)
  - 그 외: 기본 톤
- 월 탭 → 모달 닫고 해당 월로 이동 (`changeMonth` 대신 직접 `setMonth(monthStr)` 헬퍼 만들기, 슬라이드 방향은 비교해서 좌/우 결정)

**구현 노트**: 기존 `openModal()` 재사용. 헤더 `.month-display`에 `cursor: pointer` + `bindLongPress` 같은 별도 처리 없이 `click` 바인딩 (피커는 짧은 탭만으로 OK).

### 3. 현재 월이 아니면 FAB 숨김

홈/카테고리 상세 양쪽 동일.

```js
const isCurrentMonth = state.currentMonth === monthKey(new Date());
if (isCurrentMonth) app.appendChild(fab);
```

추가 시각 신호 없음 — FAB 자체가 사라지는 것만으로 충분 (불필요한 코칭 텍스트는 노이즈).

### 4. 스와이프 삭제 방향 반전 (좌→우)

`bindSwipeDelete`에서:
- 감지: `ddx < 0` → `ddx > 0` (양수 방향만 진행)
- 변환: `translateX(${ddx}px)` 그대로 (양수면 우측 이동)
- 배경 그라데이션: 우측에서 보이도록 — `rgba(165, 63, 43, ${Math.min(0.14, ddx / 600)})` (양수 비례)
- 임계값 도달: `dx > threshold`로 비교
- 삭제 애니메이션: `.is-deleting` CSS의 `translateX(-110%)` → `translateX(110%)`로 변경 (오른쪽으로 사라짐)

### 5. 콜드 스타트 시 현재 월로 리셋

`script.js` 초기화 부분:

```js
let state = loadState();
state.currentMonth = monthKey(new Date());  // 매 로드 시 강제 갱신
saveState();
```

세션 중 이전 달 둘러보는 건 그대로 동작. 페이지 reload / PWA 재실행 시에만 리셋.

### 6. 텍스트 선택 / 컨텍스트 메뉴 차단

`style.css` `body`에 추가:

```css
body {
  -webkit-user-select: none;
  user-select: none;
  -webkit-touch-callout: none;
}
input, textarea {
  -webkit-user-select: text;
  user-select: text;
}
```

기존 `.card`, `.entry`의 중복 `user-select: none` 제거.

부수 효과:
- iOS의 길게 누르기 컨텍스트 시트 차단
- Android Chrome "터치하여 검색" 차단
- 롱프레스 시 텍스트 선택 핸들 안 뜸 → 인터랙션이 깔끔해짐

## 마이그레이션

`STATE_KEY`/스키마 변경 없음. 기존 사용자 데이터 영향 없음.

## 추가: 안드로이드 뒤로가기로 모달 닫기 (260429)

`openModal()`에서 `history.pushState({ modal: true }, '')` 1회. 전역 `popstate` 리스너가 모달이 열려있으면 `closeModal()` 호출. 사용자가 취소/저장 버튼으로 닫을 때는 push해둔 entry를 `history.back()`으로 정리해 누적 방지.

기존 hashchange 라우팅과 충돌 없음 (pushState는 URL을 안 바꾸므로 hashchange 미발화).
