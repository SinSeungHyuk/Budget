# 월별 추이 통계 화면

## 배경

가계부의 본질적 가치 — "지난달과 비교해 어땠나, 이번 달 어디에 썼나"에 한 화면으로 답한다. 현재는 카테고리 상세에 들어가야 그 카테고리의 월 합계를 볼 수 있을 뿐, 월 단위 비교나 카테고리 비중 시각화가 없다.

## 진입 / 라우팅

- 트리거: 홈 화면 상단 `.summary` 영역(Total) 탭.
- 라우트: `#/stats`. `parseRoute()`/`render()`에 케이스 추가.
- 통계 화면도 `state.currentMonth`를 따른다 — 헤더에서 월을 바꾸면 도넛/바/리스트 모두 갱신.
- 안드로이드 뒤로가기: 기존 hashchange 라우팅에 따름 (홈으로 복귀).

## 화면 구조

```
[헤더 — 월 / 연도]                  ← 기존 헤더 그대로
─────────────────────────────────
이번 달 사용처
        ╭───────────╮
        │   도넛    │              ← 220×220 SVG, 비중 큰 순 진한 톤
        │  ₩1,140k  │              ← 가운데 총합
        ╰───────────╯
─────────────────────────────────
■ 식비       ₩320,000   28%
■ 교통       ₩180,000   16%        ← 색칩 + 카테고리 + 금액 + 비중
■ ...
─────────────────────────────────
월별 비교
   ▮▮▮ ▮ ▮▮ ▮▮▮ ▮▮▮ ▮▮              ← 가로 바 차트, 데이터 있는 월만
   02  03 04  05  06  07           ← 월 두 자리. 연도 변경점만 'YYYY.MM'
─────────────────────────────────
```

### 도넛

- 슬라이스: `state.currentMonth`의 카테고리별 합산. 비중 큰 순으로 슬라이스 배치.
- 색: 단일 hue 명도 변화. `--ink` 기준 `hsl()` lightness를 비중 큰 순서로 진하게 → 옅게 분포. 미니멀 톤 유지.
- 가운데 텍스트: 그 달 총합 (Manrope, 큰 글씨). 도넛 두께는 외경 110px → 내경 65px 정도.
- SVG path 직접 그리기 (`M`, `A`, `Z`). 의존성 없음.

### 카테고리 리스트

- 도넛 아래에 비중 큰 순 정렬.
- 한 줄: `[색칩] 카테고리 ₩금액 비중%`. 색칩은 도넛 슬라이스와 1:1 매칭되는 정사각형 8px.
- 탭 → `#/category/<카테고리>`로 이동.

### 바 차트

- 데이터: `getMonthTotals()` (지출 있는 월만 시간순, 최대 12개월).
- 가장 큰 월 = 100% 높이 기준. 각 막대는 `height = (total / max) * 100`%.
- 현재 `state.currentMonth` 막대는 `--ink` 진한 톤, 나머지는 `--rule-2` 옅은 톤.
- 라벨: 기본 두 자리 (`04`). 연도가 바뀌는 지점만 작게 `2026.01`.
- 탭 → 그 달로 `setMonth()` 호출, `#/stats`에 머무름 (도넛/리스트가 그 달로 갱신).

## 데이터 / 상태

`state` 스키마 변경 없음. 기존 `expenses`만 사용.

새 헬퍼 (script.js):

```js
function getMonthTotals() {
  const map = new Map();
  for (const e of state.expenses) {
    const m = e.date.slice(0, 7);  // 'YYYY-MM'
    map.set(m, (map.get(m) || 0) + e.amount);
  }
  return [...map.entries()]
    .sort(([a], [b]) => a.localeCompare(b))
    .slice(-12)
    .map(([month, total]) => ({ month, total }));
}
```

`getCategoryTotals(month)`는 기존 함수 재사용.

## 인터랙션

- 도넛 슬라이스 탭 → `#/category/<카테고리>` 이동.
- 카테고리 리스트 행 탭 → 동일.
- 바 탭 → 그 달로 `setMonth(monthStr)` 후 통계 화면 유지 (`#/stats`).
- FAB는 통계 화면에서 숨김 (홈/카테고리 화면에만 노출되는 기존 정책 그대로 적용 — `render()` 라우트 분기에서 처리).

## 빈 데이터 처리

| 조건 | 표시 |
|---|---|
| currentMonth 지출 0건 | 도넛 영역에 `∅` + "이번 달 지출 없음" 텍스트. 카테고리 리스트 숨김. |
| 전체 데이터가 1개월만 있음 | 바 차트 섹션 자체 숨김 (월별 비교 라벨도) |
| 전체 데이터 0건 | 통계 화면 진입 자체를 막음 (홈 Total이 0이면 탭 비활성화) |

## 구현 노트

### SVG 도넛

```js
function donutPath(cx, cy, rOuter, rInner, startAngle, endAngle) {
  // 큰 호 + 작은 호 결합한 path 생성
  // largeArc flag: (endAngle - startAngle) > 180 ? 1 : 0
}
```

각 슬라이스를 path 요소로 출력. 색은 `hsl(36 12% L%)` 형태로 비중 순서에 따라 L 값을 18 → 62 사이에서 균등 분포.

### 진입 애니메이션

기존 `fade-enter-r` 클래스 재사용 (`changeMonth` 패턴과 동일). 도넛 슬라이스 자체 애니메이션은 생략 (미니멀 톤, 한 번 보면 충분).

### CSS

새 클래스: `.stats`, `.stats-section`, `.donut`, `.donut-center`, `.cat-list`, `.cat-row`, `.cat-chip`, `.bar-chart`, `.bar`, `.bar-label`.

기존 토큰 재사용 (`--ink`, `--olive`, `--paper`, `--rule-*`, `--font-display`, `--font-body`, `--r-*`, `--pad`).

## 마이그레이션

스키마 변경 없음. 기존 사용자 데이터 영향 없음.

## 비목표

- 차트 라이브러리 도입
- 카테고리별 월 추이 라인 차트 (drill-down)
- 예산 대비 달성률 표시
- 통계 화면에서 직접 지출 추가 (FAB 없음)
- 통계 PDF/이미지 내보내기
- 6개월/12개월 토글 (자동으로 모든 월 표시, 12개월 cap)
