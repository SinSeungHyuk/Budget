# 고정 지출 템플릿

## 배경

매월 반복되는 지출(월세, 관리비, 통신비 등)을 매번 수동으로 입력하는 번거로움 제거. PWA라 백그라운드 실행 불가 → "앱 진입 시 그 달분 자동 등록" 모델로 우회.

## 데이터 모델

```js
state.templates: [{
  id: string,
  category: string,            // CATEGORIES 중 하나
  memo: string,
  amount: number,
  lastInsertedMonth: string,   // 'YYYY-MM' or null
  createdAt: ISO string
}]
```

`STATE_KEY` 그대로 유지. `defaultState()`에 `templates: []`만 추가 — `Object.assign` 마이그레이션으로 기존 사용자 자동 호환.

## 자동 등록 (seed)

`script.js` 초기화 시 `seedTemplates()` 1회 호출:
1. 현재 실제 월 = `monthKey(new Date())`
2. 각 template `t`에 대해 `t.lastInsertedMonth !== currentMonth`이면:
   - `state.expenses`에 새 expense 푸시 (`date: 그 달 1일 09:00`, `category/memo/amount`는 템플릿 값)
   - `t.lastInsertedMonth = currentMonth`
   - 카운터 증가
3. 카운터 > 0이면 `render()` 후 `setTimeout(showToast, 500)`

토스트: `4월 고정지출 3건 추가` 형식, 2.5초 자동 사라짐.

## UI

### 카테고리 상세 화면

```
[헤더]
─────────────
고정 지출         [+]   ← 현재 월일 때만 우측에 + 버튼
  월세      ₩420,000
  관리비    ₩180,000
─────────────
기록
  04.28 14:32  스타벅스   ₩6,500
```

표시 규칙:
- 템플릿 0개 + 현재 월: `+ 고정지출 추가` 점선 버튼 (entry point)
- 템플릿 ≥ 1 + 현재 월: 리스트 + 우측 `+` 버튼
- 템플릿 ≥ 1 + 과거/미래 월: 리스트만 (편집·삭제는 가능, 추가는 불가)
- 템플릿 0개 + 과거/미래 월: 섹션 자체 숨김
- 두 섹션 모두 표시될 때만 `기록` 라벨 노출 (단독일 땐 라벨 생략)

### 인터랙션
- 탭 = 편집 모달
- 우측 스와이프 = 삭제 (기존 `bindSwipeDelete` 재사용)

### 모달
- `openTemplateModal(cat, templateId?)` — 카테고리 prefilled, 메모/금액 입력
- 신규 생성 시: 즉시 이번 달에 expense 1건 자동 등록 (`lastInsertedMonth = currentMonth`)
- 수정 시: 템플릿만 변경, 기존 등록된 expense는 그대로 (다음 달부터 새 값 적용)
- 삭제 시: 템플릿만 제거, 기존 등록된 expense 보존

## 정책 결정

- **자동 등록 트리거**: 앱 진입 시 침묵 등록 + 토스트 알림 (사용자가 모르는 변화 방지)
- **등록 일자**: 매월 1일 09:00 고정 (월세/공과금 직관과 매칭)
- **항목 시각 구분**: 일반 expense와 동일하게 표시 (별도 마크 없음 — 미니멀 톤 유지)
- **활성/비활성 토글**: YAGNI — 필요 시 `enabled: bool` 추가
- **시드 동작 시점**: 앱 init 1회만. 세션 중 재실행 안 함

## 비목표

- 등록 일자 사용자 지정 (1~28일)
- 템플릿 일시 정지 / 비활성화
- 과거 월 소급 적용
- 카테고리 횡단 템플릿 관리 화면 (분산 관리로 결정)
